## Codebase Patterns
- 后端使用 FastAPI + Poetry 依赖管理
- 前端使用 React + Vite + TypeScript
- 日志使用 loguru（后端）和 console 分级（前端）
- 状态管理使用 Zustand
- 所有 API 端点前缀为 /api
- 项目配置使用 pydantic-settings 和 .env 文件
